SISTEM WARNET - NETBEANS

Cara membuka:
1. Extract file ZIP.
2. Buka Apache NetBeans.
3. Pilih File > Open Project.
4. Pilih folder SistemWarnet.
5. Jalankan file SistemWarnet.java.

Jika NetBeans meminta pengaturan Java Platform, gunakan JDK yang tersedia
di komputer Anda (disarankan JDK 17 atau versi yang kompatibel).
