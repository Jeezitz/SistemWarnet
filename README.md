# Sistem Warnet

## Deskripsi Project

Sistem Warnet merupakan project aplikasi berbasis console yang dibuat untuk memenuhi tugas mata kuliah Pemrograman Berorientasi Objek (OOP).

Project ini mensimulasikan sistem sederhana untuk mengelola sebuah warnet. Program dapat digunakan untuk mengelola data perangkat yang tersedia, seperti PC, Konsol, dan Laptop, serta data pelanggan dan proses penggunaan perangkat.

Dalam pengembangannya, project ini menerapkan berbagai konsep dasar Pemrograman Berorientasi Objek yang telah dipelajari selama praktikum, seperti class dan object, encapsulation, inheritance, polymorphism, interface, exception handling, serta hubungan antar class.

## Fitur Utama

- Menambahkan dan menampilkan data perangkat
- Mengelola beberapa jenis perangkat
- Mencari perangkat berdasarkan ID
- Mengelola data pelanggan
- Menampilkan informasi warnet
- Melakukan simulasi penggunaan perangkat
- Melakukan transaksi penggunaan perangkat

## Tujuan Project

Project ini dibuat untuk menerapkan konsep Pemrograman Berorientasi Objek ke dalam sebuah sistem sederhana. Selain itu, project ini juga menjadi pengembangan bertahap dari tugas praktikum sebelumnya dengan menambahkan fitur dan konsep OOP sesuai materi yang telah dipelajari.
